# Security Policy

## Supported Versions

Security fixes are applied to the latest minor release. Consumers should upgrade before reporting behavior already corrected in the latest version.

## Reporting a Vulnerability

Use GitHub's private vulnerability reporting for this repository. Do not disclose suspected SQL injection, cross-tenant event exposure, unsafe header propagation, replay bypass, or sensitive payload retention in a public issue. Include affected versions, configuration, impact, and a minimal reproduction without production payloads, credentials, or broker addresses.

Maintainers will acknowledge a complete report within five business days and coordinate remediation and disclosure.
